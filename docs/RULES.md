# 炸金花规则说明

本文是游戏规则的唯一权威来源。服务端实现、前端展示都以本文为准。
括号中的 `xxx` 是对应的房间配置字段名，完整配置见文末「房间配置」。

---

## 1. 基础

- 一副 52 张牌，去掉大小王，每局重新洗牌（服务端使用加密安全随机数，Fisher–Yates 洗牌）。
- 每个房间最多 15 个座位，至少 2 名玩家才能开局。15 × 3 = 45 ≤ 52，牌够用。
- 每人发 3 张暗牌。
- 点数：A(14) > K(13) > Q(12) > J(11) > 10 > … > 3 > 2。
- 花色默认不分大小，只用来判断同花；仅在 `tieRule = suit` 时用于比较。花色顺序：♠ 黑桃 > ♥ 红桃 > ♣ 梅花 > ♦ 方块。

## 2. 牌型（从大到小）

| 排名 | 代码 | 名称 | 说明 |
|---|---|---|---|
| 1 | `baozi` | 豹子 | 三张点数相同 |
| 2 | `shunjin` | 顺金 | 同花顺 |
| 3 | `jinhua` | 金花 | 同花，不连 |
| 4 | `shunzi` | 顺子 | 连续，不同花 |
| 5 | `duizi` | 对子 | 两张点数相同 |
| 6 | `sanpai` | 单张 | 以上都不是 |

### 2.1 顺子与 A（`a23`）

- QKA 永远是最大的顺子 / 顺金。
- KA2 永远不算顺子。
- A23 的处理由 `a23` 决定：
  - `lowest`（默认）：A23 是最小的顺子，A 当 1。顺序：QKA > KQJ > … > 234 > A23。
  - `second`：A23 是第二大的顺子。顺序：QKA > A23 > KQJ > … > 234。
  - `none`：A23 不算顺子，按 A、3、2 的单张 / 金花处理。

### 2.2 特殊牌 235（`baozi235`、`baozi235Suit`）

- 由点数 2、3、5 组成的牌。
- `baozi235`：
  - `all`（默认）：235 可以吃所有豹子。
  - `aaa`：235 只能吃 AAA。
  - `off`：没有 235 规则。
- `baozi235Suit`：
  - `mixed`（默认）：三张花色不全相同才算特殊 235；同花的 2、3、5 是普通金花。
  - `any`：同花的 2、3、5 也能吃豹子。
- 235 只在对上豹子时有特权。对上其他牌型时，按它自身的牌型正常比较：花色不同时是最小的单张，同花时是最小的金花。

### 2.3 同牌型比较

| 牌型 | 比较方法 |
|---|---|
| 豹子 | 比点数 |
| 顺金 / 顺子 | 按 2.1 的顺序比较 |
| 金花 / 单张 | 三张从大到小排列，逐张比较点数 |
| 对子 | 先比对子点数，再比单牌点数 |

### 2.4 完全相同（`tieRule`）

- `challengerLoses`（默认）：点数完全相同时，主动发起比牌的一方输。
- `suit`：比较“最大那组牌”中花色最大的一张。单张、金花、顺子、顺金比最大的那张牌；对子比对子里花色较大的那张。因为每张牌唯一，这样一定能分出胜负。
- 强制开牌没有发起者。如果在 `challengerLoses` 下出现完全相同，并列者平分底池，除不尽的余数给按行动顺序最靠前的那位。

## 3. 一局的流程

### 3.1 参与者

- 每一局开始前（包括一场的第一局），座位上**已离线超过 10 秒**的玩家自动改为观战模式（积分保留，同一场里坐回来恢复）。刚断线不到 10 秒的保留座位，照常参与本局。
- 开启“额外领分”（`rebuyMax > 0`）时：开局前积分不够付底注的入座玩家，自动补领一份初始积分（额度不足一份时补剩下的），直到本场累计补领达到 `rebuyMax`。
- 本局开始时，已入座、且积分 ≥ 底注（`ante`）的玩家参与本局。
- 积分不够底注的玩家本局不参与，状态为 `sittingOut`，座位保留。
- 如果符合条件的玩家不足 2 人：
  - 座位上至少 2 人、其余都是积分不足，且离座的本场玩家也没有积分了（其他人输光）→ 本场提前结束，进入结算。
  - 否则（有人改为观战模式或退出）→ **本场暂停**，不开新局，等待玩家入座。同一场里坐回来，积分保持不变；观战者也可以入座补位。有积分的玩家够 2 人后，按“局间等待”倒计时继续。暂停期间房主可以手动结束本场。

### 3.2 开局

1. 每位参与者支付底注 `ante`，放入底池。
2. 庄家：本场第一局在参与者中随机选；之后由上一局赢家坐庄。赢家本局不参与时，由上一任庄家顺时针的下一位参与者坐庄；平分底池时取赢家中行动顺序最靠前的。
3. 发牌，每人 3 张。发牌后**所有人都处于闷牌状态**，服务端不向任何人下发牌面，包括本人。
4. 座位号 0–14 按顺时针排列。从庄家顺时针的下一位参与者开始行动。

### 3.3 注额

- 当前单注 `currentBet` 统一按**闷牌价**记录，开局等于 `ante`。
- 闷牌玩家每次实际支付 `currentBet`；明牌玩家实际支付 `currentBet × seenMultiplier`。
- 例如 `seenMultiplier = 3`、`currentBet = 10`：闷牌跟注付 10，明牌跟注付 30（重庆玩法）。

### 3.4 轮次

- 以庄家下一位为起点，按顺时针排行动顺序。轮到的人在行动顺序里的位置**不大于**上一个行动者时，轮次 `round` 加 1。
- 第一个行动者行动时 `round = 1`。
- 已弃牌、已出局的玩家直接跳过。

### 3.5 随时可做的操作（不占用回合）

- **看牌 `look`**：本局中只要没弃牌、没出局，随时可以看自己的牌。看完 `seen = true`，之后按明牌价支付。看牌不可撤销。
- **弃牌 `fold`**：本局中未出局的玩家随时可以弃牌，不必等轮到自己，已下的注不退。轮到自己时弃牌，回合交给下一位。

### 3.6 轮到自己时的操作（四选一）

设 `price(x) = seen ? x × seenMultiplier : x`。

| 操作 | 条件 | 实际支付 | 效果 |
|---|---|---|---|
| 跟注 `call` | 积分 ≥ `price(currentBet)` | `price(currentBet)` | 回合结束 |
| 加注 `raise` | 档位模式：`to = ante × step`（来自加注档位）；自由模式：`to` 为任意整数。都要求 `currentBet < to ≤ ante × capMultiple`，且积分 ≥ `price(to)` | `price(to)` | `currentBet = to`，回合结束 |
| 比牌 `compare` | `round > compareAfterRound`；闷牌时还要求 `blindCanCompare = true`；积分 ≥ 比牌费用 | 比牌费用 = `price(currentBet) × compareCost` | 与指定的另一名在场玩家比大小，输者出局；回合结束 |
| 弃牌 `fold` | 随时 | 0 | 出局 |

额外规则：

- **孤注一掷 `allIn`**：只有在 `shortStack = allIn`，并且积分 < `price(currentBet)`（连跟注都不够）时才能使用，不受轮次和闷牌限制。玩家把全部剩余积分放入底池，同时和**所有**其他在场玩家比牌，发起方按“发起比牌者”处理平局。
  - 赢所有人：本局结束，他赢得整个底池。
  - 只要输给任何一人：他出局，其他人不受影响，牌局继续。
- `shortStack = foldOnly` 时，积分不足以跟注的玩家只能弃牌。
- 加注方式 `raiseMode`：`steps`（默认）只能选加注档位；`free` 可以加到任意整数金额，档位仍作为快捷按钮。
- 加注档位 `raiseSteps` 是底注的倍数。界面只展示 `> currentBet`、`≤ 封顶`、且付得起的档位。
- 支付金额永远不会超过玩家现有积分，积分永远 ≥ 0。

### 3.7 比牌时谁能看到牌

- 比牌胜方能看到负方的牌。胜方如果是闷牌，**仍然保持闷牌**：看不到自己的牌，之后也继续按闷牌价支付。
- 比牌负方能看到双方的牌（他已经出局）。
- 其他玩家和观战者只看到“谁和谁比、谁输了”。
- 孤注一掷按每一对比牌分别套用上面两条。

### 3.8 超时（`actionSeconds`、`timeoutAction`）

- 每次轮到某人时开始倒计时 `actionSeconds` 秒，掉线玩家同样计时。
- 超时后执行 `timeoutAction`：
  - `fold`（默认）：弃牌。
  - `call`：跟注；积分不够时改为弃牌。
- 某玩家在一局里超时过，就记为“该局超时”。**连续 2 局超时**的玩家，在本局结束后自动改为观战模式，积分保留。

### 3.9 本局结束

满足任一条件即结束：

1. 只剩 1 名未弃牌、未出局的玩家 → 他赢。结束原因 `lastStanding`。
2. 孤注一掷成功 → 发起者赢。结束原因 `allIn`。
3. 第 `maxRounds` 轮全部行动完毕，即将进入第 `maxRounds + 1` 轮时 → **强制开牌**：所有在场玩家亮牌，所有人可见，最大者赢。结束原因 `showdown`。
4. 房主提前结束本场 → 本局作废，每人退回本局已下的全部积分（含底注）。结束原因 `voided`。

结算：

- 赢家获得整个底池。
- **喜钱**（`bonusEnabled`）：赢家唯一，且他的牌是豹子或顺金时，本局其他每位参与者额外付给赢家 `ante × bonusBaozi`（豹子）或 `ante × bonusShunjin`（顺金），积分不够的付光为止。触发喜钱时，赢家的牌自动向所有人亮出。
- 本局结束后，每位参与者都能看到**自己**的牌。
- 赢家可以在下一局开始前选择**亮牌 `show`**，向所有人展示。
- 弃牌者的牌永远不向其他人公开。

### 3.10 局间

- 一局结束后倒计时 `nextHandSeconds` 秒（默认 5 秒），自动开始下一局。期间可以入座、改为观战模式、亮牌。
- 打满 `hands` 局后，最后一局的结果展示 `settleSeconds` 秒（默认 5 秒），然后本场结束，进入结算。

## 4. 场与积分

- 「场」= 房主点一次“开始”到结算，包含 `hands` 局。
- 入座时发放 `initialChips` 初始积分。
- 同一场里改为观战模式后再坐下，**恢复原来的积分**，不会重新发放。
- 每一场开始时，所有入座玩家的积分重置为 `initialChips`。
- 房主可以“再来一场”：回到准备阶段，可修改除 `initialChips` 以外的配置。
- 房间记录每一场的输赢，并显示**历场累计输赢**：每场的 净输赢 = 场末积分 − 初始积分 − 本场补领的积分。

## 5. 房间配置

开房时可配置。准备阶段房主可修改；开局后不能修改；`initialChips` 创建后永远不能修改。

| 字段 | 含义 | 默认 | 取值 |
|---|---|---|---|
| `hands` | 局数 | 5 | 1–100 整数；快捷：5 / 10 / 20 / 30 |
| `initialChips` | 初始积分 | 1000 | 100–100000 整数；快捷：200 / 500 / 1000 / 2000 |
| `rebuyMax` | 额外领分上限（每人每场） | 0（不允许） | 0–1000000 整数；快捷：0 / 1000 / 5000 / 10000 |
| `ante` | 底注 | 1 | 1–1000 整数；快捷：1 / 2 / 5 / 10 |
| `raiseMode` | 加注方式 | `steps` | `steps`（固定档位）/ `free`（自由加注） |
| `raiseSteps` | 加注档位（底注倍数） | `[5, 10, 20, 30, 50, 100]` | 1–6 个严格递增的整数，每个 2–100，且都 ≤ `capMultiple` |
| `capMultiple` | 单注封顶（底注倍数，闷牌价） | 100 | 2–100 整数；快捷：5 / 10 / 20 / 50 / 100 |
| `seenMultiplier` | 明牌倍率 | 3 | 1–5 整数 |
| `maxRounds` | 轮数上限 | 100 | 5–200 整数；快捷：10 / 15 / 20 / 50 / 100 |
| `compareAfterRound` | 第几轮结束后可比牌 | 1 | 1 / 2 / 3 |
| `actionSeconds` | 每次行动限时（秒） | 80 | 10–180 整数；快捷：30 / 60 / 80 / 120 |
| `nextHandSeconds` | 局间等待（秒） | 5 | 3–60 整数；快捷：5 / 10 / 15 / 20 |
| `settleSeconds` | 最后一局结束到出结算榜的等待（秒） | 5 | 3–60 整数；快捷：5 / 10 / 15 / 20 |
| `timeoutAction` | 超时处理 | `fold` | `fold` / `call` |
| `a23` | A23 处理 | `lowest` | `lowest` / `second` / `none` |
| `baozi235` | 235 吃豹子 | `all` | `all` / `aaa` / `off` |
| `baozi235Suit` | 235 花色要求 | `mixed` | `mixed` / `any` |
| `tieRule` | 完全相同时 | `challengerLoses` | `challengerLoses` / `suit` |
| `compareCost` | 比牌费用倍数 | 1 | 1 / 2 |
| `blindCanCompare` | 闷牌可主动比牌 | `true` | `true` / `false` |
| `shortStack` | 积分不足以跟注时 | `allIn` | `allIn`（孤注一掷）/ `foldOnly`（只能弃牌） |
| `bonusEnabled` | 喜钱 | `true` | `true` / `false` |
| `bonusBaozi` | 豹子喜钱（底注倍数） | 10 | 0–100 整数 |
| `bonusShunjin` | 顺金喜钱（底注倍数） | 5 | 0–100 整数 |

> 边池（side pot）不支持。积分不足时的处理只有“孤注一掷”和“只能弃牌”两种。
